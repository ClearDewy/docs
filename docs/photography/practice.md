# 拍摄与复盘：用一次单变量练习检验判断

## 覆盖范围与验收产物

本次复习覆盖观看、拍摄曝光与光线、明暗、色彩、双方向调色和参考分析。你需要手机或相机，以及能独立保留照片的设备；预计现场 20 分钟、编辑 20 分钟、复盘 5 分钟。没有相机时可以先用内置示例完成概念验收，但请把实拍栏写为「未完成」，不要把网页操作当成现场拍摄。

最后应留下：一句拍摄意图、一条有来源的参考记录、三张只改变一个主要条件的实拍、选定图的原图与 A/B 版本，以及一段解释失败原因的复盘。完成日期由你记录；建议第二天不看参数先复看一次，一周后换一个场景再次测试。

## 不查资料先回答

1. 快门从 1/200 秒改为 1/50 秒，其他条件不变，时间曝光改变几档？
2. 蓝色天空是否能作为必须校正到中性的白平衡参照？
3. 直方图偏左是否足以认定照片失败？
4. 原图 / A 对比能回答什么，A / B 对比又能回答什么？
5. 「画面给我安静感」应怎样连接到可见证据？

先把答案写到本地笔记，再打开本页底部答案。能背出定义却不能指认画面变化，仍需要回到相应实验。

## 实现任务：窗边杯子的一组对照

选用[拍摄课](/photography/capture)的杯子练习，避免为了作业寻找危险或无法重复的场景。先写意图：「让杯子看起来安静、有体积，保留亮面的细节和暗面的轮廓。」在参考图板里写一个借鉴动作，例如「侧面光线让主体从亮到暗逐渐过渡」。不需要杯子和山景外观相同，你是在迁移光线关系。

固定杯子位置、背景与取景大小，拍三张不同相机方向的照片，使窗分别位于正面、侧面、背后。记录哪些条件没有完全固定，例如手机自动曝光、自动 HDR 或自动白平衡。选一张最能支持意图的图导入调色台，保留原始文件。为它做 A「接近现场观察」和 B「个人表达」两版；不要为了与内置山景数值相同而硬套参数。

A 先检查亮度与中性物体，B 在 A 的思路上只选一两个有理由的变化。组件没有复制版本按钮时，可以手动按 A 的参数填写 B；记录每项新增变化。导出项目 JSON 和两张 PNG，刷新并恢复一次，确认文件确实可用。

## 复盘表：区分原因所在

| 问题 | 要看什么证据 | 下一次行动示例 |
| --- | --- | --- |
| 主体不突出 | 背景是否更亮、更杂，位置是否抢眼 | 拍摄前移动杯子或改变机位 |
| 细节模糊 | 原图是否已经模糊，对焦位置是否正确 | 改善对焦、支撑或快门，而非加饱和 |
| 亮部没有纹理 | 原图中该区域是否已经全白 | 重新拍摄时调整曝光或光线反差 |
| 暗面显得很平 | 关闭暗部提升后体积是否回来 | 减小暗部参数 |
| 白杯偏色 | 光是否混杂，冷暖/色偏是否过大 | 先简化光源，再分开调整颜色 |
| 两版只有数值不同 | 同位置对比是否真的看出效果 | 说明差异太小，或重新审视意图 |

这张表要求你先判断问题发生在拍摄还是后期。处理顺序可以改变，但补救不能违反信息边界：已经记录成同一个白值的区域无法凭空恢复真实纹理。

## 评分与补学

每项 0–2 分：0 分没有证据，1 分产物存在但解释不清，2 分产物与解释对应。共五项：意图包含主体与保留条件；对照拍摄记录变量；A/B 差异可见且有原因；来源与许可完整；JSON 能恢复照片与参数。达到 8 分并不意味着成为专业摄影师，只说明这条基础练习链已经闭合。任何一项 0 分，都应补完再进入新分支。

常见错误是同时改变机位、光线、曝光和滤镜，却把所有效果归因于一个参数。这时回到[观看课](/photography/seeing)与[明暗单变量实验](/photography/tone)，重新固定输入。来源不清则回到[参考图板](/photography/references)，操作能保存但不能解释则回到[双方向实验](/photography/two-directions)。

## 参考答案

1. 时间增加 4 倍，即增加两档；运动记录也可能更明显。
2. 不能，天空本来可能是蓝色，不能把物体颜色误当照明偏色。
3. 不足。低调场景可能合理偏左，要结合主体可读性和意图。
4. 原图 / A 检查每次处理改变了什么；A / B 比较两个方向的取舍。两者都不自动判断哪版更好。
5. 例如「主体附近没有强亮点干扰，颜色较克制，明暗过渡较缓，所以我感到安静」。这是你对效果的解释，不是对拍摄者内心的确认。

开放实践没有唯一数值答案。用原图证据、单变量对照和恢复测试证明你确实完成了自己的判断。
