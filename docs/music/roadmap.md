# 音乐知识地图

这张地图面向零基础学习者。最初不需要五线谱、乐器经验或唱名知识；如果「半音」「一拍」还不清楚，就从第 1 课开始。下表中的已可学表示有正文、练习和答案；它不等于个人已掌握，也不等于真实演奏已验证。

## 已可学：一条连续的入门路径

| 学习单元 | 直接依赖 | 过关证据 |
| --- | --- | --- |
| [1. 听见一格](/music/foundations) | 无 | 在台阶上数出 C 到 E 的四步，再解释 D 到 F 的三步 |
| [2. 五根弦与三个音](/music/guitar-chords) | 第 1 课 | 把五个实际音高归为 C/E/G，解释关掉重复音的变化 |
| [3. 大调与调内和弦](/music/major-key) | 第 1、2 课 | 从 C 大调叠出 Dm、G 和 Bdim，不靠背名称 |
| [4. 节奏和伴奏](/music/rhythm) | 第 1 课；用第 2 课 C 指型练伴奏 | 72 BPM 下完成四拍一小节，解释八分细分为何没让拍速翻倍 |
| [5. 原创两小节练习](/music/first-song) | 第 2、3、4 课 | 给 C D E G｜F E D C 配上 C｜F、G、C，并逐拍解释 |
| [6. 声乐选调与复盘](/music/voice-and-review) | 第 1、5 课 | 移调 −2 半音，比较两端范围；完成一条可复查的课堂笔记 |

主线可读作「音高 → 和弦与拍点 → 调内关系 → 整句表现 → 练习反馈」。第 3、4 课可以互换阅读顺序，但应在第 5 课之前都完成。

## 第一阶段如何验收

先不看答案，独立完成以下任务，再回对应课核对：

1. 逐弦写出 C 指型：X、C3、E3、G3、C4、E4；解释其中三个不同音级与五个发声弦的区别。
2. 让节奏实验保持 72 BPM，切换每拍 1 格与 2 格；指出一拍始终约 0.833 秒。
3. 把 C4 D4 E4 G4｜F4 E4 D4 C4 整体降两个半音，得到 Bb3 C4 D4 F4｜Eb4 D4 C4 Bb3。
4. 用「第 2 小节第 3 拍提前；下次 60 BPM 只练这个换和弦」取代「节奏不好」。若只有模拟，记录为模拟；若用录音，保留原文件和时间位置。

任意一步无法解释时，回到对应 lesson 重做同一个例子。这里不展开新的知识，只负责定位依赖与验收。

## 后续主题：尚未完成课程

这些节点是未来范围，不是可以直接学习的空壳文章。

| 分支 | 后续顺序 | 进入条件 |
| --- | --- | --- |
| 基础乐理 | 五线谱与节奏记谱 → 小调 → 调号与五度圈 → 调式 | 完成音名、大调与四拍练习 |
| 听觉训练 | 音程辨听 → 节奏听写 → 旋律模唱 → 和弦功能听辨 | 能把听到的声音对应到当前例子的音程和拍点 |
| 吉他 | 稳定按弦与换和弦 → 扫弦/分解伴奏 → 横按与换把 → 指板连接 | 实琴逐弦清晰并保持拍速；浏览器不能代验 |
| 和声与歌曲 | 七和弦 → 终止式 → 借用和弦 → 真实歌曲段落分析 | 能从音阶构造调内三和弦 |
| 声乐与录音 | 呼吸/发声协调 → 换声区 → 乐句表达 → 收音与编辑 | 有实际练习反馈，技术问题需结合现场教学 |
