# 曝光与暗部：两种变亮有什么不同

同一张山景，想看清树林，又不想把白云推成一片白，该调哪里？先用下面的照片试一次。预计练习 15–20 分钟。

## 把刚才看到的变化说清楚

**曝光**让画面整体变亮。树林变亮时，原本已经很亮的云也会继续变亮；几种不同的白色挤到同样的白，云纹就不容易分辨了。

**暗部**更偏向提亮原来较暗的像素。因此它更适合先试着看清树林，但并不认识树林或天空，也不是只改某一块位置。提得太多，树林内部的深浅差别也可能变弱。

决定下一步时，先说位置：是整张都暗，还是只有树林看不清？再改一个参数。每次都回到同一处云纹和树林对照。

<details><summary>直方图怎么看？</summary>

图中的灰柱是原图，绿柱是当前图，使用同一比例。横轴从黑走向白，柱越高，表示这种亮度出现得越多。它不记录位置，所以一根亮柱无法告诉你来自云还是岩壁。先看照片，再用图表确认整体向亮处或暗处移动。

已经完全变白的 JPEG 区域，即使调暗，也不能恢复原来不存在的纹理。本实验是浏览器中的近似调色，并非 RAW 显影；参数与专业软件同名滑块的数值不通用。
