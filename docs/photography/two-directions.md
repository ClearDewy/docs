# 一张原图，两个方向：完成可恢复的调色实验

## 实验问题、环境与固定输入

待验证命题是：同一张照片可以产生两种清楚不同的气氛，但两版都应保留你事先选定的重要信息。完成[明暗](/photography/tone)与[色彩](/photography/color)两课后再操作；本实验使用现代桌面或手机浏览器，无需相机、账号、专业软件或付费素材。预计 40 分钟。

固定输入为 Hannes Röst 的 [Fronalpstock big.jpg](https://commons.wikimedia.org/wiki/File:Fronalpstock_big.jpg)，使用 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) 的 1280px 缩略图。原作是已后期处理的拼接全景，画面是绿色山体、浅色岩壁、深色林地与蓝天白云。本案例是本站设计的教学实验，不是真实客户项目，不代表拍摄者原本的表达意图。「原图」仅指进入本次实验的基线 JPEG。

组件把工作图最长边缩到 1200px，参数计算版本为本站 `photography-lab-v1`（2026-09-09）。图片和参数在当前浏览器本地处理；不会上传到服务端。导出的是工作分辨率，不是相机全尺寸文件。

## 先定义两种方向

A 版的意图是「清凉、安静，保留山体层次」。你要盯住中央浅色岩壁、深色林地和白云；颜色可以略冷，但岩壁不能蓝得失去自然感。B 版的意图是「温暖、明快，让前景草坡更亲近」。它可以稍亮稍暖，但不能把云朵推成没有细节的大白块。共同约束是：岩壁、林地与草坡仍可区分。

两种感觉是本站对效果的主观选择；参数和图像变化是可复查的观察。你可以不喜欢其中一版，但要能解释哪项变化没有服务于意图。

## 完整操作路径

1. 点击「载入内置山景（重置两版）」。这一操作会替换当前图并把 A/B 都恢复为 0；有自己的项目时先导出 JSON。载入过程中显示加载提示并暂时禁用编辑和重复导入；待提示恢复为保存状态后再操作。
2. 选择「编辑 A」，在意图框写上 A 的目标。先依次输入曝光 -0.15、亮部 -20，观察云和岩壁；再输入冷暖 -25、饱和度 -15。其余参数维持 0。
3. 选择「编辑 B」，记录 B 的目标。先输入曝光 +0.15、暗部 +15，再输入冷暖 +25、饱和度 +10，其余为 0。
4. 或点击「应用课文 A/B 参数」一次填入上述数值，然后逐项关闭勾选来验证原因。这个按钮会覆盖两版参数和意图；它只是可复现起点，不是适用于所有照片的最佳预设。
5. 先选择「原图 / 当前版本」。拖动分界线，让分界经过中央岩壁和云层；键盘用户可聚焦图片，用左右方向键移动。分别检查 A 和 B。
6. 再选择「A / B 两版」，比较同一位置。点击「展开明度直方图」查看当前编辑版本的统计；需要同时看三张时展开并排视图。
7. 对一项有疑问的调整，先关闭勾选，再打开。↺ 只把这一项数值归零；「重置当前版参数」将这一版所有数值归零，保留另一版和意图。

## 预期输出、实际观察与解释

预期得到同一工作图、两句意图、两组独立参数，以及 A/B 两张效果图。A 应相对偏冷、稍暗、颜色稍淡；B 应相对偏暖、稍亮、颜色稍鲜。它们是方向预期，不是客观审美评分。请自己记录三个可见观察，例如「A 的白云较克制」「B 的草坡更亮」「B 的云边仍可辨」。若只写「A 高级、B 普通」，还没有完成可复查分析。

把 B 的冷暖关掉后，B 仍应保留较亮和暗部提升的效果，说明不同阶段没有被混为一个不可拆的滤镜。把所有阶段关闭，图像应回到原图；恢复时每项保留之前的数值。若两个版本完全一致，先检查是否点错编辑版本、勾选是否关闭，以及两版数值是否实际相同。

## 保存、导出与恢复验收

参数与意图编辑后会自动写入 localStorage；你也可以点击「立即保存」。本地记录包括压缩后的工作照片、A/B 参数和意图、当前编辑版本与比较方式。刷新之后应恢复同一张图和同样的 A/B 结果。不同页面使用同一实验台，所以在明暗课调整的内容会出现在本页。

点击「导出 JSON 备份（含照片）」，文件名为 `photography-project.json`。随后把 B 曝光改为 -1，再导入刚才的 JSON；B 应恢复为 +0.15，意图和照片也恢复。JSON 含图片数据，不能只用一份手抄参数表代替。导入是替换当前项目；无效 JSON、不支持的图片和过大文件会拒绝，当前有效编辑保留。

分别选择 A 和 B，点击导出 PNG。对于内置示例，再点击「下载素材署名 JSON」，其中有作者、来源、许可、变更说明和当前参数；再分发调色图时，把署名、许可链接和修改说明放到可见图注或随附文件，并按 CC BY-SA 3.0 或兼容许可分享。图片与署名单独点击下载，避免浏览器拦截自动多文件下载；也可从项目 JSON 和本页图注取得署名，不要只发一张无归属的图片。

如果内置浏览器没有开始文件下载，展开「无法下载文件？复制 / 粘贴 JSON 备份」，点击「生成备份文本」，在文本框全选复制并保存为本地 `.json` 文本文件。恢复时粘贴完整文本，点击「从粘贴文本恢复」；它与文件导入使用同一验证路径，包含工作照片、意图、A/B 参数及视图选择。文本很长是因为内嵌了图片，不要只复制开头几行。

浏览器缓存可能被清理，隐私模式或存储配额也可能禁止保存。看到保存失败提示时，编辑仍在当前页面，但刷新后不保证保留；立即下载 JSON。导出照片移除 EXIF，不替代原始素材备份。

## 常见失败与限制

文件选择仅接收 12MB 以内 JPEG、PNG、WebP；超过 4000 万像素的图会拒绝，备份 JSON 上限 4MB。先在系统工具里缩小照片再导入，不要重命名 HEIC 为 JPG。图片解码失败时检查实际格式。透明 PNG 保留透明通道，完全透明像素不参与直方图。

工作台的曝光是 sRGB 线性增益近似，冷暖是通道增益，饱和度与色相来自全局 HSL。没有 RAW 解码、降噪、局部蒙版、镜头矫正、肤色保护或显示器校准。程序在本地图片和同源示例上读写 Canvas，避免任意远程地址污染画布；参考图链接不会自动被拿来做 Canvas 调色。

## 自测、验收与清理

1. 只关闭 B 的冷暖，是否应把 B 的暗部也恢复到 0？
2. 导出 PNG 能否保证下次恢复全部参数？
3. 在另一个照片上套用同样数值，是否可以保证相同气氛？

<details><summary>答案与过关标准</summary>

1. 不应。关闭某阶段只移除它的作用。
2. 不能。PNG 是最终像素，恢复可编辑参数需要含照片的项目 JSON。
3. 不能。原始照明、颜色、曝光、主体都不同，需要重新判断。

过关标准：含照片 JSON 能恢复两版；两张导出图确有差异；能指出至少一项调整的收益和代价；知道哪些变化并非现场真实记录。不再使用当前项目时，可先导出，再载入内置示例替换浏览器中的工作图。
