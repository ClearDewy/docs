# 用同一句旋律练习选调与录音复盘

## 高音够不到时，怎样保留整句关系

沿用[上一课](/music/first-song)的 C4 D4 E4 G4｜F4 E4 D4 C4。本课不教具体发声技术，而是练习两个基础能力：**整句一起移动，比较高低两端；用记录定位一个可重做的问题。** 不需要麦克风权限，也不要求上传个人录音。可以只用浏览器算例和纸面复盘样例完成知识练习。

## 移调保留的是相邻关系

**移调**是把全部音一起升高或降低相同的音程。原句相邻半音差是 +2、+2、+3、−2、−1、−2、−2。全部降低两个半音后：

**Bb3 C4 D4 F4｜Eb4 D4 C4 Bb3**。

最高音由 G4 变成 F4，最低音由 C4 变成 Bb3，相邻距离全部保持。原来在 C 大调的 1 2 3 5｜4 3 2 1，现在仍是这些级数，但调变成 Bb 大调。伴奏也应同移：原来的 C、F、G 对应 Bb、Eb、F，不能只移动人声而让伴奏原样保留。

把全句降低十二个半音是下降一个八度：调名仍可叫 C 大调，音域却变成 C3–G3。调名不够描述演唱高度，必须同时说明旋律八度。吉他变调夹可把固定指型整体升高，但每加一品也会升高发声；它不自动保证适合某个人的演唱范围。

4. 将示例下界改为 Bb3。预期所有音都落在 Bb3–F4。先试听，再核对级数和相邻距离保持。只有范围覆盖得到验证，并没有自动证明能唱好。
5. 改为 +4 半音，观察 E 大调的拼写 E4 F#4 G#4 B4｜A4 G#4 F#4 E4。调内音名字母按级数正确拼写，不能把 F# 随手写成 Gb 后仍称它是第 2 级。
6. 导出 JSON，恢复默认，再导入文件。预期回到自己的移调和示例边界，保持停止。数据在本机，录音未被收集。

## 音域覆盖与实际舒适是两层判断

**音域**是所讨论声音的最低到最高音；**常用音区**关心一段音乐大多停在哪里、持续多久。两段旋律即使最低最高音相同，一段只偶尔碰到高音，另一段反复持续高音，演唱负担也可能不同。元音、力度、乐句长度、换声区域和当天状态都不是这两个边界能概括的。

因此，选调可以先排除明显超出当前练习范围的候选，再在自己已有的舒适发声方式中试短句，记录「哪个音、哪个字、持续多久、感觉如何」。不要为完成网页指标硬顶高音。持续不适或嘶哑时停止练习并寻求合适的专业帮助；本页不作声音诊断，也不提供医疗判断。

## 不依赖麦克风的课堂录音复盘

使用你已经合法持有、适合个人复习的课堂录音，在本地播放器打开；没有录音就先用下面**教学假设样例**练习写记录。网页不内置录音器，也不上传文件。文件建议保留原件，笔记另存，避免反复覆盖。

一次只复盘 20–40 秒。先完整听一次，只记录位置；第二次围绕一个问题重听，例如是否提前、某音是否总偏低、换和弦是否停顿。不能只凭一个截图或波形形状断定音准与发声质量。

| 字段 | 教学假设样例（非真实录音测量） |
| --- | --- |
| 文件 / 片段 | 自己的练习 01；00:12–00:20；第二小节 |
| 目标 | 60 BPM 下完整唱/弹 F E D C，并保持换和弦点 |
| 可观察现象 | 重听两次，第三拍 G 和弦都晚于口数「3」 |
| 暂时解释 | 可能因前一和弦松手太迟；需用单独换指练习核对 |
| 下一次只改一项 | 只练 F F G C，降低到 50 BPM，先不唱 |
| 复测标准 | 连续三遍在第三拍换到 G，口数不中断；保留第二段录音比较 |

「可观察现象」与「原因猜测」必须分开。教师说「尾音不稳」，先在笔记中保留原话的短摘要和时间位置，再写自己的可测练习，不擅自替换成没有依据的生理解释。若想观察音准，应先有正确参考音与可靠分析工具；当前页面只提供合成参考，未做录音音高提取。

实际步骤：建立一条上述格式的笔记 → 只重听选定短片段 → 填一个现象 → 设计一次可比较的改变 → 下一次按相同片段与条件复测。如果没有录音，就把样例中的「第三拍晚」改写成假设记录并标明「纸面练习」，不能填成真实观察。

## 自测与答案

1. 原句降两个半音，最高和最低分别是什么？伴奏 C 应变成什么？
2. 示例舒适范围 C4–F4，降低两半音是否让整句全部合适？
3. 全部落在输入范围内，能否判定演唱没有困难？
4. 「00:16 第三拍迟了；因为气息不足」中，哪部分是观察，哪部分还需验证？

<details><summary>核对答案</summary>

1. 最高 F4，最低 Bb3，C 和弦应变成 Bb。
2. 不会，最低 Bb3 低于 C4。对本例 C4–F4 只有 5 半音宽，而旋律宽 7 半音，任何整体移调都不能完整装入。
3. 不能。范围是必要的初步信息，持续时间、音区和发声状态仍需实际观察。
4. 在有录音与拍参照支持时，「00:16 第三拍迟了」是观察；「因为气息不足」是未经验证的解释，不能由迟拍直接推出。

</details>
