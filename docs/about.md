# 关于

这里是 Dewyx 面向自己的长期学习知识库，围绕六个方向组织内容：

- [智能算法](/ai/)：模型、训练、LLM、Agent 与 Harness 工程；
- [系统工程](/systems/)：传统软件系统、分布式系统与工程实践；
- [嵌入式](/embedded/)：嵌入式软件、电子硬件与物理系统。
- [量化研究](/quant/)：从市场机制和研究证据到风险、组合与执行。
- [音乐](/music/)：从听觉、节奏和和声基础到吉他、曲目实践与录音复盘。
- [摄影](/photography/)：从观看、拍摄控制和影调色彩到作品实践与素材复盘。

站点优先记录可以复用、可以验证、能够逐步连接成体系的知识，而不是追求独立文章的数量。知识页面的成熟度与本人演奏、拍摄或审美熟练度分开记录；作品、录音、老师反馈和结构化复盘是实践证据。
