# 摄影：先看见，再拍摄与调色

摄影并不从记住所有参数开始，而是从一句话开始：**我想让人先看见什么，感受到什么？** 本专栏给没有摄影和后期基础的读者一条完整路径。手机即可完成第一轮练习；没有自己的照片，也可以用合法内置的山景照片开始。

![瑞士 Fronalpstock 的深色山坡、绿色山体与远山](/photography/fronalpstock.jpg)

这张照片会贯穿课程：先辨认前景山体的岩壁和草坡如何引导视线，再理解为什么不能一味把暗处拉亮，最后做清凉与温暖两个版本。这里的「原图」指本次实验的基线 JPEG，保留它是为了比较调整，不意味着它未经任何处理。

## 按这个顺序学

| 学习单元 | 你会做出的结果 | 预计时间 |
| --- | --- | --- |
| [1. 先指出位置，再说为什么喜欢](/photography/seeing) | 在图上指出区域，遮挡对照，留下一条事实与动作 | 10–15 分钟 |
| [2. 拍摄、曝光与光线](/photography/capture) | 用同一场景解释快门、光圈、ISO 和光线方向 | 35 分钟 |
| [3. 曝光与暗部：两种变亮有什么不同](/photography/tone) | 对照云纹与树林，预测并验证单一调整 | 15–20 分钟 |
| [4. 白平衡与色彩](/photography/color) | 区分冷暖、色偏、色相和饱和度 | 30 分钟 |
| [5. 一张原图，两个方向](/photography/two-directions) | 可恢复、可比较的 A/B 调色项目 | 40 分钟 |
| [6. 参考图分析](/photography/references) | 带作者、出处和实践想法的参考图板 | 25 分钟 |
| [7. 拍摄与复盘](/photography/practice) | 一组对照照片与可验证的复盘记录 | 45 分钟 |

[知识地图](/photography/roadmap)解释依赖和后续分支；[素材采集](/photography/material-collection)是可选工具课，需要本地 Node.js 环境。基础课程只需要浏览器，不以安装专业软件为前提。

## 什么算完成第一轮

选一张照片，不借助预设名称解释主体和意图；先完成明暗，再完成色彩；保留原图和两种方向；隔一天重新打开 JSON 备份，仍能说清每一项调整的原因。最后亲自拍一组照片，把一个参考图中的观察变成拍摄动作。网页练习留下你的观察和操作记录；是否理解，还要看能否独立解释，并在新照片里复用。

## 当前范围与建设状态

当前基础主线为可学习初版，覆盖数字照片的观察、基础拍摄、浏览器 sRGB 近似调色、参考管理与复盘。教程实验是教学示例，尚不代表读者完成了实拍。后续的人像布光、RAW 显影、局部蒙版、曲线精修、打印色彩管理留在知识地图，不用薄介绍伪装成完整课程。
