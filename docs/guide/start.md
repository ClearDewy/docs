# 使用这个知识库

这个站点是面向自己的长期知识库：保留经过整理、验证、未来还会复用的知识，不以更新频率或文章数量为目标。

## 内容组织

- [智能算法](/ai/)：传统算法与模型、深度学习、LLM、Agent、训练、推理和 Harness 工程。
- [系统工程](/systems/)：操作系统、网络、数据库、分布式系统、软件架构和工程可靠性。
- [嵌入式](/embedded/)：电子基础、MCU/SoC、RTOS、驱动、通信协议、PCB 和机器人。
- [量化研究](/quant/)：市场与统计、点时数据、因子证据、验证、风险成本、组合与执行。
- [音乐](/music/)：听觉、节奏、音高与和声，吉他与曲目练习，以及录音反馈。
- [摄影](/photography/)：观看、拍摄控制、影调与色彩，参考拆解、作品练习和素材复盘。

Python、C++、Linux、吉他型号、相机型号和后期软件等属于横跨专栏的工具或二级主题，不单独成为一级专栏。新增文章应先在对应专栏的知识地图中找到位置，再进入文章流。

新增或重构内容应先遵循[知识文档体系规范](/guide/knowledge-documentation-standard)，再根据需要使用站点内置的[交互式知识组件](/guide/interactive-components)。

## 一篇笔记应当包含什么

尽量回答四个问题：

1. 要解决什么问题？
2. 结论是什么？
3. 结论怎样得到或验证？
4. 哪些条件变化后，结论可能失效？

::: tip 写作原则
能够运行的示例交给自动化验证；不能自动验证的观察，明确写出环境和日期。音乐与摄影用录音、照片、老师反馈或结构化自评留下可复查证据，但不把主观判断包装成客观分数。
:::

这里的四个问题用于快速自查。不同类型页面的完整模板、成熟度和完成标准见[知识文档体系规范](/guide/knowledge-documentation-standard)。
