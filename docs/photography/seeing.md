# 先指出位置，再说为什么喜欢

先不用记术语。点一下中央岩壁，看看它和旁边的树林有什么不同；再遮住天空，比较目光是否移动。预计练习 10–15 分钟。

## 从一句观察，到下一次拍摄

「这张照片很美」还没告诉你下次怎么拍。「中央岩壁比旁边的树林亮」指出了位置和差别，这是一条**可见事实**。

接着说：「这个差别让我先看见岩壁。」这是你对观看效果的**解释**。换一个人，第一眼也可能落在白云上；回到图上比较，不需要替作者猜心情。

最后留下一个**行动**：「下次拍山景，保留亮岩壁旁边的暗树林，再拍一张去掉树林的版本。」两张图让你有办法检查这个关系是否有用。

## 现在再认识三个词

你最想讲的对象叫**主体**，本例可以选中央山体；第一眼抓住注意的位置叫**视觉入口**，它可能是岩壁，也可能是亮云。你希望观看者获得的感受与要保留的关系，合起来形成这次拍摄的**意图**。

试着用一句话收束：「我想突出中央山体，让画面安静，同时保留岩壁和树林的明暗差。」有了这个条件，下一步调整亮度时，就知道该回哪里检查。
