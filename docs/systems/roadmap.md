# 系统工程知识地图

## 计算机系统基础

- 编程语言、类型系统、编译与运行时：先实践[本地 Python 项目准备](/systems/python-project-workflow)
- 操作系统、进程线程、内存与文件系统
- 网络协议、连接管理、代理与负载均衡

## 数据、存储与服务

- 数据建模、事务、索引与查询优化
- 缓存、消息队列、对象存储与搜索系统
- API、服务端框架、身份认证与权限控制

## 分布式系统

- 一致性、复制、分区、共识与故障模型
- 分布式事务、任务系统与事件驱动架构
- 容量、延迟、可用性和成本之间的权衡

## 软件架构与工程方法

- 模块边界、依赖管理、接口与演进策略
- 测试、持续集成、可复现构建与发布
- 代码审查、技术债、迁移和兼容性

## 运行与可靠性

- 容器、编排、基础设施即代码与云平台
- 日志、指标、追踪、告警与事件响应
- 性能分析、容量规划、韧性与安全工程
