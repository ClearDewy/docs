# 摄影知识地图

这条地图面向零基础读者，先建立观看判断，再引入技术。不要因为已经打开了调色软件，就跳过「我为什么要这样调」。完成一个节点的证据是具体产物，而不是浏览记录。

```text
在照片上指出位置、比较差别
  → 拍摄：光线方向、快门、光圈、ISO
  → 明暗：曝光与暗部的单变量对照
  → 色彩：白平衡、色偏、HSL
  → A/B 实验：同一原图的两个方向
  → 参考图板：可见事实 → 借鉴动作
  → 实拍与复盘
       ↘ 可选：Pexels 官方 API 素材采集
```

## 后续分支

以下节点尚未构成课程，不作为已完成知识：构图与焦段的系统练习、自然光人像、闪光灯与多灯布光、RAW 显影、局部蒙版和曲线、相机色彩配置与显示器校准、组照编辑与叙事、输出和打印。它们依赖当前主线的观察、曝光和色彩判断，不依赖某个软件品牌。
