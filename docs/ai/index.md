# 智能算法

这个专栏研究一个完整问题：**机器怎样从数据中形成可验证的能力，并被构造成可靠的智能系统？**

这里不是模型名词表。章节导览负责定位，概念课负责讲清一个问题，实验负责产生证据，参考页负责快速查询，复习页负责确认掌握。当前第 0–7 章已经形成一条可连续学习、操作和验收的主路径。

默认读者有数学与线性代数基础；“初学者”指尚未学习模型与相关工程。Python 本地环境可在[项目准备](/systems/python-project-workflow)补齐。概念自测、模拟实验和独立实现分别记录，互不替代。

## 两条阅读路径

### 第一次系统学习

```text
0 模型计算基础 → 1 机器学习与泛化评估 → 2 神经网络 → 3 注意力与 Transformer
                                      ↓
                            4 基础模型 → 5 训练 → 6 评测 → 7 智能系统
```

从[矩阵乘法](/ai/foundations/matrix-multiplication)开始最稳妥。每完成一章，先做实验和阶段复习，再进入下一章。

### 带着工程问题查询

按 `问题 → 数据 → 表示 → 模型 → 训练 → 评测 → 推理 → 反馈` 横向查阅。任何“效果变好”都要能指出基线、数据范围、指标和没有被证明的部分。

## 学习约定

- 公式先标语义和 shape，再推导；代码先写输入、输出和不变量，再谈框架 API。
- 动画必须回答一个认知问题。播放时同时显示当前对象、当前运算和当前结果；看不动效也能从静态说明得到同一结论。
- 实验必须固定输入或随机种子，给出预期输出、判断条件和失败排查。
- 项目和框架只是证据来源，不决定知识树。
