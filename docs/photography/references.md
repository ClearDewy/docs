# 参考图分析：把喜欢变成下一次能做的动作

先在示例照片里点一处，读出它和邻近区域的差别；再换一个区域写自己的观察。完成后会把区域名称与笔记一起保存在下方图板。预计练习 15–25 分钟。

<ClientOnly><PhotographyReferenceBoard /></ClientOnly>

## 怎么判断这条笔记能不能用？

「山景很清爽，想拍同款」没有指出下一步。试着把它改成：「中央岩壁比旁边树林亮；下次取景时，把两者同时留下，再拍一张只留岩壁的图作比较。」

这条记录有位置、有可见差别、有可做的对照。你可以对气氛有自己的解释，但从一张照片不能确认作者的心理，也不能唯一反推出相机与后期参数。

<details><summary>收藏更多图片、备份与导入</summary>

展开图板中的「收藏新参考」，填写标题、作者、来源页面和观察。可以附加自己有权保存的本地缩略图，也可以只记链接。来源与许可保留在每张卡片的展开区。

图板支持 JSON 导出与合并导入；已有条目会保留。若浏览器不能下载，可用「复制 / 粘贴图板 JSON」。最多 100 条、约 3.5MB，输入文件最多 4MB。导出可能含缩略图，分享前核对图片的使用条件。

[素材采集课](/photography/material-collection)提供官方 API 清单导入。清单保留作者和出处；导入后仍要对着图写出自己的观察。工具不会替你分析图片。
