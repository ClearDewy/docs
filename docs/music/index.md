# 音乐

从零开始，先弄清「弹了什么音、什么时候弹」，再把乐理、吉他和声乐连接起来。不需要识谱，也不假定你知道和弦是什么。首批主线用一个 C 和弦和一段原创八音旋律贯穿；浏览器里可以试听、改指板、改节奏和移调。

这一专栏以可重复的小练习建立听觉与动作的联系。浏览器能准确呈现音名、品位与时间关系；吉他的手感、真实音色、自己的发声舒适度仍需要实际练习。页面的 `learnable` 是内容状态；工程检查与新手实际学懂、演奏或声乐验收分别记录。前两课已改成分步样板，是否容易理解仍需要实际学习反馈。

## 从这里开始

| 顺序 | 已经可学的内容 | 完成后能做什么 |
| --- | --- | --- |
| 1 | [听见一格：从声音认识半音](/music/foundations) | 点响相邻台阶，比较 3 / 4 步，再换起点数距离 |
| 2 | [五根弦，为什么只有三个音？](/music/guitar-chords) | 看指板逐弦亮起，把五个声音归三组，去掉重复音再听 |
| 3 | [大调、级数与调内和弦](/music/major-key) | 从 C 大调叠出七个三和弦，读懂 I–IV–V–I |
| 4 | [节奏与第一种伴奏](/music/rhythm) | 用 72 BPM 数四拍，区分拍速、细分与重音 |
| 5 | [完成一首两小节练习](/music/first-song) | 把原创旋律、和弦与拍点对齐，找到可解释的落点 |
| 6 | [选调与课堂录音复盘](/music/voice-and-review) | 整句移调并比较音域，用时间戳记录一个练习问题 |

建议每次只完成一课，用 20–35 分钟做完步骤并写下自测答案。没有吉他时可先用指板模拟，记录「模拟通过」；以后拿到吉他再补实际逐弦验收。第 6 课也可以用已有录音或纸面样例，不要求提供麦克风权限。

## 学习边界与后续主题

当前内容覆盖入门的十二平均律、标准调弦、三和弦、基础大调、4/4 节奏和移调。系统识谱、听写、小调与七和弦、调式、和声分析、吉他换把、声乐技术和录音制作列在[知识地图](/music/roadmap)的后续主题中，尚未作为已完成课程提供。

入门阶段的综合过关标准是：不看答案说明 C 指型为什么有五个发声音、保持拍速改变细分、把八音旋律整体降低两个半音，并用一条带时间戳的记录说明下一次练习要改变什么。完成主线后回到[知识地图](/music/roadmap)检查薄弱点，不必因为菜单中有更多术语就跳过基础。
