# 听见一格：从声音认识半音

**练习约 15–20 分钟。** 不用识谱，也不用乐器。先回答一个可以听见的问题：**同一个声音向上挪一点，会发生什么？** 下面每个台阶都是一个能点响的声音。从第一个播放按钮开始，跟着亮框听；看完一格，再比较三格和四格。

## 回看刚才：为什么起点要写 0

想象站在楼梯的一个台阶上，还没迈步，这就是起点。迈到隔壁算一次移动，再迈到下一个才算第二次。**我们数的是移动次数，不是把所有站过的位置都数进去。**

实验把最初的声音叫 C4。先不用记整套字母，只把它当作能随时重听的起点。从 C4 走到旁边的 Db4，移动一次；从 Db4 再到 D4，又移动一次。C4 到 D4 因而是两步，虽然字母看起来只是 C 接着 D。字母不是等间距的尺，台阶才是本实验用来数距离的尺。

在本课采用的十二平均律中，相邻这一小格叫**半音**。走两格是两个半音，也叫**全音**。例如 D4 → Eb4 → E4 是两格；E4 到 F4 只有一格，中间没有再藏着一个声音。网页把每格画成一样宽，是为了让你看到“移动几次”；它不是音量表，向右走也不表示要更用力或更大声。

## 三步和四步的差异在哪里

A 和 B 都从 C4 出发：A 的终点是 Eb4，走了三次；B 的终点是 E4，走了四次。A 的终点比 B 低一格，起点不动，所以两音距离缩小一格。你可以用“先后两个声音”听距离，也可以直接看终点的位置。第一次听不出区别，就交替重听 A、B，不需要闭眼猜。

**两音之间的距离叫音程。** 这个例子里的 C–E 是“大三度”，C–Eb 是“小三度”。“大、小”在这里说明具体音高距离，不是规定音乐必须快乐或悲伤。为什么两者都叫“三度”？因为 C 到 E 数字母位置是 C、D、E 三个；Eb 仍使用 E 这个字母，只是降低了一格。

所以有两种不同的数法：**三度的“三”数音名字母位置，四个半音的“四”数实际移动次数。** 先用台阶把声音距离算清，再慢慢认识名称。不需要用名字反过来猜台阶。

## 把数字看成声音所在的高低层

C3、C4、C5 都叫 C，但高度不同。下节吉他课会同时出现 C3 和 C4：你会听到较低的 C 和较高的 C。后面的数字用来区分它们所在的层，不表示弹第几根弦、按第几品或弹几次。

从 C4 连续向上走十二个半音，来到 C5，这段距离叫一个**八度**。现在只要记住“同名也可以不同高”就够了；下一课会用两根实际发声弦把这件事听出来。

<details><summary>想查完整的一层音、升降号或频率公式时，再展开</summary>

这里使用科学音高记号，中央 C 记为 C4。从 C4 向上到 C5 的十二次移动依次为：

C4 → Db4 → D4 → Eb4 → E4 → F4 → Gb4 → G4 → Ab4 → A4 → Bb4 → B4 → C5。

`b` 是降号 ♭，例如 Eb 读“降 E”；`#` 是升号 ♯，例如 C# 读“升 C”。在十二平均律下，C# 和 Db 可以对应同一个音高，这叫等音。课程当前选 Db、Eb 来标小台阶，之后音阶课会解释为什么不同场合需要不同拼写。

频率说的是每秒振动次数。向上一个半音，频率乘以 $2^{1/12}$；走完十二格，频率变为两倍。这个公式解释均分的关系，不是本课操作的前提。严格的音程名称同时依赖字母拼写与半音数，因此不能在所有语境下把“三个半音”一律写成“小三度”。

</details>

## 关掉声音，换个例子检查

你已在实验中从 D4 走到 F4。再试着只看这一段：**E4 → F4 → Gb4 → G4**。

1. E4 到 G4 移动了几次？把每一次“从哪里到哪里”说出来。
2. 如果把终点从 G4 退回 Gb4，距离会增加还是减少？
3. C3 与 C4 是同一个名字的高低版本，还是同一实际高度？

<details><summary>核对推理，不只核对数字</summary>

E→F 第一次，F→Gb 第二次，Gb→G 第三次，所以共三个半音。起点不计步；中间有两个位置，不表示只有两次移动。终点退回 Gb 后剩两次移动，距离减少一个半音。C3、C4 名字相同、实际高度不同，C4 高一个八度。

无脚本或无声音时，上面这条带箭头的路径仍可用来数距离；听觉比较留待能播放时补做。答对文字题，并不代表已经能听辨所有音程。

</details>
