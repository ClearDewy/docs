## 能力阶梯

| 阶段 | 能做什么 | 主要证据 |
| --- | --- | --- |
| 电路观察者 | 识别电源、地、节点、支路和负载 | 手算 + 虚拟仪表 |
| 裸机开发者 | 从复位启动并控制 MCU 外设 | 固件 + 寄存器 + 波形 |
| 实时系统开发者 | 设计中断、任务和时序预算 | trace + 最坏时间分析 |
| 硬件系统开发者 | 读原理图、检查供电和接口边界 | ERC/DRC + 实测波形 |
| 设备工程者 | 处理升级、掉电、故障与生产测试 | 故障注入 + 恢复记录 |

## 实验分层

- **浏览器实验**：建立因果关系，允许任意修改数值，无损坏风险；
- **面包板实验**：验证接线、电压、电流、时序和器件容差；
- **开发板实验**：验证启动、寄存器、外设、中断和 RTOS；
- **系统实验**：验证供电、通信、故障恢复、功耗和环境边界。

浏览器结果只能证明模型和计算正确，不能证明真实器件、接线、探头或供电正确。

## 专题分支

完成第 5 章后，可以进入嵌入式 Linux；完成第 6–7 章后，可以进入机器人、电机控制和自制 PCB；边缘智能还直接依赖[智能算法主线](/ai/)。分支不会插入必修主线中间。
